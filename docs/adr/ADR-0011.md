# ADR-0011: Space visual baseline after founder-family UAT

Status: **ACCEPTED — FINAL PASS — OWNER CONFIRMED** · Date: 2026-10-05 · Phase: 1V

## Context and bounded evidence

The historical Phase 1V candidate compared Space Explorer, Adventure Trail and Number Lab as three visual alternatives over one identical scripted semantic flow. Founder-family qualitative human UAT is now complete. Authorized aggregate findings were immediate start, understood activities, clear Home navigation and safe retry; Explore attracted attention, while help discoverability, Shapes and concrete support for symbols required improvement.

This small founder-family observation is project design input only, not representative preference research, educational-effectiveness evidence, accessibility certification or mathematical-ability evidence. No individual sessions, ages, timings, mistakes, child-linked quotations, media or raw behavioral notes are included. Historical engineering evidence remains in the [Phase 1V report](../PHASE_1V_COMPLETION_REPORT.md).

Manual reproduction of the original Shapes choices, hint/retry/success and navigation paths passed mechanically; no event/state failure was reproduced. The human-reported unsatisfactory Shapes experience originally blocked acceptance. Observed presentation problems included a generic activity heading, a less prominent matching instruction, letter-coded choices, unequal target/choice artwork sizes and a help control below the initial narrow viewport. These justified concrete presentation remediation while the child-specific cause remained unknown. The owner has now confirmed that remediated Shapes is acceptable; this does not establish the original child-specific cause.

## Decision

The owner selects **Space Explorer**, with its dark blue background and light typography, as canonical Phase 1V and the primary project visual baseline. Retire B/C production theme switching and ignore legacy `variant` queries rather than keep unused visual machinery. Preserve the historical three-alternative rationale and verification evidence in documentation.

Keep the reconciliation bounded to a clear visible same-shape match with identical unlabeled target/choice artwork, more discoverable child-controlled `Show me` / `Δείξε μου` help near the choices, and sixteen unit tiles as the concrete anchor before multiplication, square power and principal-root representations. Symbols remain optional unscored discoveries, not access prerequisites. Record observed mechanics separately from UX inference and final owner acceptance.

Keep one array rather than duplicate diagrams. It is shown first before any symbol is selected, then within the selected step, retaining the same sixteen cells and logical row/column positions. This addresses an observed narrow-viewport case where selecting a later formula left the highlighted array offscreen. The accepted final root view highlights only the four top tiles and uses one top bracket labelled `4`; the sixteen-tile square and short side caption precede the smaller concluding `√16 = 4`. It depicts principal square root and side length, not all solutions of x² = 16. Preserve formula order and child control without automatic scrolling or overlays. Guidance avoids duplicate descriptions; the root guide remains empty because the control's unique descriptions already provide its side and principal-root meaning.

Use only tiny incomplete prototype-only el-GR/en-GB copy. Only one exact `lang=en` selects English; all absent, unsupported, case-changed, malformed or repeated values select Greek. This deterministic UAT default is documented, not a locale-fallback architecture. German remains deferred to Phase 1D.
